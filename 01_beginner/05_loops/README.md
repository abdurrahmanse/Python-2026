# 05 — Loops

Repeat work with `for` and `while`. Use `break`, `continue`, and `pass` to control flow, and combine loops for nested iteration.

## Subfolders

1. `01_for_loops/` — iterating over sequences
2. `02_while_loops/` — loop while a condition is true
3. `03_nested_loops/` — loops inside loops
4. `04_break_continue_pass/` — control statements
5. `05_loop_practice/` — small practice problems

## Run them in order

```bash
for d in 0?_*; do python3 "$d/app.py"; done
```
