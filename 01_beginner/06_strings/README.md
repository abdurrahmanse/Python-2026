# 06 — Strings

Strings in depth: slicing, common methods, and formatting with f-strings, `format()`, and `%`.

## Subfolders

1. `01_basics/` — creating strings, escaping, raw strings
2. `02_slicing_and_indexing/` — `[start:stop:step]`
3. `03_methods/` — `split`, `join`, `replace`, `find`, `strip`, etc.
4. `04_formatting/` — f-strings, `.format()`, `%` formatting

## Run them in order

```bash
for d in 0?_*/; do python3 "$d/app.py"; done
```
