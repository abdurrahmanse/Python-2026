# 01 — Setup and Basics

Get Python installed and learn the absolute basics: how to run a script, write comments, and read input from the user.

## Subfolders

> _This topic is a starting point — run scripts directly from the topic root while you explore._

Start with:

```bash
python3 --version
python3 hello.py
```

## What's covered

- Installing Python (3.x)
- Running `.py` scripts from the terminal
- `print()` and basic output
- Comments (`#`)
- `input()` for reading user input
