# 02 — Variables and Data Types

Learn how to name values, the built-in data types Python gives you, and how to convert between them.

## Subfolders

1. `01_variables_and_data_types/` — declaring variables, `type()`, `int`, `float`, `str`, `bool`
2. `02_type_conversion/` — `int()`, `float()`, `str()` and casting rules
3. `03_multiple_assignment_and_constants/` — tuple unpacking and the `ALL_CAPS` convention for constants

## Run them in order

```bash
python3 01_variables_and_data_types/app.py
python3 02_type_conversion/app.py
python3 03_multiple_assignment_and_constants/app.py
```
