# 07 — Functions

Define reusable blocks of code, pass data in, get results back, and explore scoping rules.

## Subfolders

1. `01_defining_functions/` — `def`, calling, return basics
2. `02_arguments_and_parameters/` — positional, keyword, `*args`, `**kwargs`, defaults
3. `03_return_values/` — single and multiple return values
4. `04_lambda_functions/` — anonymous one-line functions
5. `05_scope/` — local, enclosing, global, built-in (LEGB)
6. `06_recursion/` — functions that call themselves
7. `07_higher_order_functions/` — passing functions as arguments

## Run them in order

```bash
for d in 0?_*/; do python3 "$d/app.py"; done
```
