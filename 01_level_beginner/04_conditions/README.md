# 04 — Conditions

Make decisions with `if`, `elif`, and `else`. Combine conditions, nest them, and use logical operators.

## Subfolders

1. `01_if_else/` — basic branching
2. `02_nested_conditions/` — `if` inside `if`
3. `03_logical_operators/` — `and`, `or`, `not` inside conditions

## Run them in order

```bash
python3 01_if_else/app.py
python3 02_nested_conditions/app.py
python3 03_logical_operators/app.py
```
