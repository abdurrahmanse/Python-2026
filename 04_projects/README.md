# 04 — Projects and Practice

Put it all together with hands-on projects, grouped by difficulty.

## Subfolders

1. `01_beginner_projects/` — small, single-file projects
2. `02_intermediate_projects/` — multi-file projects with tests
3. `03_advanced_projects/` — packages, APIs, and databases
4. `04_challenges/` — algorithm and problem-solving drills

## Setup

```bash
pip install -r requirements.txt
```

## Suggested order

```bash
for d in 0?_*/; do python3 "$d/app.py"; done
```
