# 07 — Comprehensions, Iterators, Generators

Idiomatic Python: build collections in one expression with comprehensions, and stream values lazily with generators.

## Subfolders

1. `01_list_comprehensions/` — `[f(x) for x in xs if cond]`
2. `02_dict_set_comprehensions/` — `{...}` and `{...}` variants
3. `03_iterators/` — the iterator protocol, `iter()` and `next()`
4. `04_generators/` — `yield`, generator expressions, lazy evaluation

## Run them in order

```bash
for d in 0?_*/; do python3 "$d/app.py"; done
```
