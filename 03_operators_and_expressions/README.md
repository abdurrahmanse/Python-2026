# 03 — Operators and Expressions

Combine values into expressions using arithmetic, comparison, logical, and assignment operators.

## Subfolders

1. `01_arithmetic_operators/` — `+`, `-`, `*`, `/`, `//`, `%`, `**`
2. `02_comparison_operators/` — `==`, `!=`, `<`, `<=`, `>`, `>=`
3. `03_logical_operators/` — `and`, `or`, `not`
4. `04_assignment_operators/` — `=`, `+=`, `-=`, `*=`, `/=`, `//=`, `%=`, `**=`

## Run them in order

```bash
python3 01_arithmetic_operators/app.py
python3 02_comparison_operators/app.py
python3 03_logical_operators/app.py
python3 04_assignment_operators/app.py
```
