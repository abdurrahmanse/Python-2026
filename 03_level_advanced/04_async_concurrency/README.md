# 18 — Async and Concurrency

Run multiple things at once: cooperative multitasking with `asyncio`, or true parallelism with threads and processes.

## Subfolders

1. `01_asyncio/` — `async def`, `await`, `asyncio.run`, tasks
2. `02_threads_processes/` — `threading` and `multiprocessing`

## Setup

```bash
pip install -r requirements.txt
```

## Run them in order

```bash
python3 01_asyncio/app.py
python3 02_threads_processes/app.py
```
