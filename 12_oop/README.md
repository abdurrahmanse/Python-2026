# 12 — Object-Oriented Programming

Model real-world things with classes. Encapsulate state, reuse through inheritance, and customize behavior with magic methods.

## Subfolders

1. `01_classes_objects/` — class syntax, `__init__`, instances
2. `02_attributes_methods/` — instance vs class attributes, methods
3. `03_inheritance/` — subclassing and `super()`
4. `04_polymorphism/` — same interface, different behavior
5. `05_encapsulation/` — convention-based privacy (`_` and `__`)
6. `06_magic_methods/` — `__str__`, `__repr__`, `__len__`, `__eq__`, etc.

## Run them in order

```bash
for d in 0?_*/; do python3 "$d/app.py"; done
```
