# 11 — Errors and Exceptions

Handle errors gracefully with `try` / `except`. Raise your own exceptions. Use `finally` and `assert`.

## Subfolders

1. `01_try_except/` — catching and recovering from exceptions
2. `02_raise_custom_errors/` — defining your own exception classes
3. `03_finally_and_assert/` — cleanup with `finally`, sanity checks with `assert`

## Run them in order

```bash
for d in 0?_*/; do python3 "$d/app.py"; done
```
