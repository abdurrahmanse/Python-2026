# 10 — File Handling

Read and write text files. Parse CSV and JSON. Use `with` so files always close.

## Subfolders

1. `01_read_files/` — `open()`, `read()`, `readline()`, iteration
2. `02_write_files/` — write and append modes
3. `03_csv_json/` — the `csv` and `json` modules

## Run them in order

```bash
for d in 0?_*/; do python3 "$d/app.py"; done
```
