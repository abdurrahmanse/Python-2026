# 07 — Data Structures

The four built-in container types: list, tuple, set, dict. How to nest them and which methods to reach for.

## Subfolders

1. `01_lists/` — ordered, mutable sequences
2. `02_tuples/` — ordered, immutable sequences
3. `03_sets/` — unordered collections of unique items
4. `04_dictionaries/` — key/value mappings
5. `05_nested_data_structures/` — lists of dicts, dicts of lists, etc.
6. `06_common_methods/` — frequently used methods per type

## Run them in order

```bash
for d in 0?_*/; do python3 "$d/app.py"; done
```
