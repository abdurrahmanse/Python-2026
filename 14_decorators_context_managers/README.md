# 14 — Decorators and Context Managers

Wrap functions to add behavior with decorators. Manage resources with the `with` statement and `@contextmanager`.

## Subfolders

1. `01_decorators/` — function decorators, `*args`/`**kwargs` forwarding, `functools.wraps`
2. `02_context_managers/` — class-based and `@contextmanager`-based managers

## Run them in order

```bash
python3 01_decorators/app.py
python3 02_context_managers/app.py
```
